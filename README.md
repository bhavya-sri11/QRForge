QRForge — QR Code Studio

Create. Customize. Download.

QRForge is a web-based QR code studio designed to make QR code creation simple, accessible, and convenient. It provides an interactive interface for generating QR codes, previewing results, and working with the available customization and export options.

🚀 Overview

QR codes provide a convenient way to share information through a simple scan. QRForge aims to make creating them a straightforward experience through a web-based interface.

The project brings together a frontend application, QR code generation functionality, and a live deployment so users can explore the application directly in their browser.

Project goals:

- Simplify the QR code creation process.
- Provide a user-friendly interface.
- Make the application accessible through a live web link.
- Build practical experience in frontend development and deployment.

✨ Features

- QR Code Generation — Create QR codes using the inputs supported by the application.
- Interactive Interface — Work with QR code creation through a browser-based user interface.
- Preview — View the generated QR code within the application, if supported by the current build.
- Customization — Explore available QR code styling and configuration options.
- Export and Download — Save generated QR codes using the download options available in the application.
- Web Accessibility — Access the deployed application without setting up the development environment locally.

Note: The available features depend on the current deployed version.

💻 Getting Started

Follow these steps to run QRForge locally.

Prerequisites

Install the following:

- "Node.js" (https://nodejs.org/) — use a version compatible with the project.
- npm — included with Node.js.
- Git — for cloning the repository.

Installation

1. Clone the repository

git clone https://github.com/bhavya-sri11/QRForge.git

2. Navigate to the application directory

The application currently resides in the "qrforge" subdirectory.

cd QRForge/qrforge

3. Install dependencies

npm install

4. Start the development server

npm run dev

5. Open the local application

Open the local URL displayed in your terminal, commonly:

http://localhost:5173/

You can now explore the application locally and make changes to the source code.
